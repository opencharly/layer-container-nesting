# 2026.267.1829 — docs(skill): the build-time /tmp corruption RCA (the pre-pull trigger)

## Summary

Adds the **build-time `/tmp` corruption** RCA to the `container-nesting` skill —
sourced to this candy because its pre-pull step IS the trigger.

**Mechanism (RCA 2026-09-24).** A BuildKit cache mount rooted under `/tmp`
combined with a nested container runtime that writes under `/tmp` in the same RUN
makes BuildKit materialise `/tmp` at the process umask (`0755`) instead of the
lower layer's `1777`; the change is committed into the image, and every uid-1000
writer of `/tmp` EACCESes (`supervisord` `logfile=/tmp/supervisord.log`,
pod-dbus `/tmp/dbus-session`). Either factor alone is harmless:

| cache dst | nested runtime in the same RUN | image `/tmp` |
|---|---|---|
| — | — | 1777 |
| `/tmp/npm-cache` | no | 1777 |
| outside `/tmp` | yes | 1777 |
| `/tmp/npm-cache` | yes | **755** |

This candy's pre-pull is exactly that combination, so **any** box composing
`container-nesting` was affected. The section documents the build-scope detect,
the two-layer fix — the **root** fix (emitter caches off `/tmp`) as a named batch
member of opencharly/distro-cachyos#95, plus a **temporary** box-level belt
(`chmod 1777 /tmp`) that is retired when the root fix lands — and that a
`download:` staging into `/tmp` as uid 1000 is a downstream victim.

### The mechanism — pasted (a), (b)

The controlled 2×2 on a real image (base unmodified, exact emitted RUN shape):

```
$ podman build -f Dockerfile.A ...   # cache dst=/tmp/npm-cache + nested podman pull
$ podman run --rm --entrypoint /bin/sh rca-a -c 'stat -c "A /tmp=%a %U:%G" /tmp'
A /tmp=755 root:root
$ podman build -f Dockerfile.B ...   # cache dst=/var/cache/charly/npm-cache + nested podman pull
$ podman run --rm --entrypoint /bin/sh rca-b -c 'stat -c "B /tmp=%a %U:%G" /tmp'
B /tmp=1777 root:root
```

Instrumented probes inserted around the two steps of the emitted `charly-selftest`
Containerfile (`distro-cachyos`), showing `/tmp` go `1777 → 755` at the pre-pull:

```
STEP 37/107: RUN stat -c "PROBE-after-xdgmkdir /tmp=%a %U:%G" /tmp
PROBE-after-xdgmkdir /tmp=1777 root:root
STEP 71/107: RUN stat -c "PROBE-before-download /tmp=%a %U:%G" /tmp
PROBE-before-download /tmp=755 root:root      # <- container-nesting pre-pull ran between
STEP 71/107: ... cp -f "$__c" /tmp/claude-code-install.sh ...
cp: cannot create regular file '/tmp/claude-code-install.sh': Permission denied
```
