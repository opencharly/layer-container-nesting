# 2026.321.0754 — fix(tailscale)!: add the ubuntu-26.04 section with the resolute apt suite

## Summary

Adds an **`ubuntu-26.04:` section** to this candy's `distro:` map so a 26.04 image gets the **resolute**
tailscale apt suite. The existing `ubuntu-24.04:` section keeps `noble`, untouched.

Head `79cf609`, **1 file, 12 insertions(+), 0 deletions(-)**.

```yaml
ubuntu-24.04:   # unchanged — noble
    repo: tailscale … noble.noarmor.gpg / suite: noble
ubuntu-26.04:   # NEW — package: tailscale + repo: resolute
```

My first attempt rewrote the `ubuntu-24.04` block in place; that would have declared a 24.04 section serving
the 26.04 suite and broken 24.04 consumers, so the versioned key is **added** instead.
